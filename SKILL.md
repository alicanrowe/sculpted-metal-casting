# Sculpted metal casting

Use this skill to design cast-metal pieces that have to look hand-carved and liquid, not CAD-made, and that have to cast. It covers two scales that share one kit:

- **Jewelry** (rings, cuffs, ear pieces, clips, studs, pendants, necklaces) printed in castable wax and cast in sterling.
- **Furniture-scale castings** (the worked example is a sawhorse with a removable leather seat) built with the same kit in centimetres.

The code is in `scripts/`. The rules that came out of real review rounds are in `references/`. Read the references before you design anything. They hold every correction a client has already had to make once.

## Before you start
1. **Do what was asked, no more.** Quote the client's words for the job before you start. "Match X's close-ups", "same layout as X" or "re-render" means new views of the current model: no geometry change. Change geometry only where the client's words ask for it ("fix the moth rig", "the feet look like elf shoes"), keep everything else, and say in the report which parts changed. A brief written for another thread quotes the client and lists what must not change.
2. Read `references/style-rules.md`, `references/casting-rules.md`, `references/buildable.md` and `references/client-picks.md` (details the client has said they love: reuse them, don't check them away). Then read the shared `design-taste` skill (`../design-taste/` next to this skill): `principles.md`, `banned-moves.md`, and `domains.md` for metal. Score every design with its `rubric.md` before showing it.
3. Look for a project aesthetic brief (for example `AESTHETIC.md`). If there is none, write one from `references/brief-template.md` with the client's words and the named reference artists. Never copy a reference: borrow its hand, not its pieces.
4. Set up Python 3.13: `pip install bpy==5.3.0 numpy scipy scikit-image trimesh manifold3d pillow numba`. `numba` is required (`sdf.py` uses it). Run shell scripts with `bash`.
5. If the brand has a theme (fonts, colours, logo), use it for every sheet and caption you make.

## Workflow
1. **Brief and influences.** Write down which influences lead and by how much (for example 50 / 30 / 20). For a set of variants, give each variant one lead influence and push it hard; see `references/influence-weighting.md`.
2. **Build in the kit.** A piece is a Python function that returns `(Scene, stones)`. Build it from strokes that swell and taper (`sculpt.ribbon`, `v2.blade`), carved feathers and petals (`moira.py`), wings (`wings2.py`), the carved abdomen (`abdomen.py`) and calibrated stones (`kit.calibrate`, `moira.prong`, `v2.claws`). Register it in a `PIECES` dict. `references/kit-map.md` lists what each module does.
2b. **Dense carved ornament over a heavy form** (signets, domed heads, wide bands, cuff fronts): use the insert-and-layer kit instead (`scripts/kit/layer.py`, worked example `dome_layer.py`) and read `references/insert-layer.md`. A heavy blank, one or two sculpted elements placed hundreds of times in tiers over a stippled ground, one exact union (`dome_layer.py`), then `finish.py` (the DynaMesh step: voxel remesh, close every pinhole tunnel, re-cut the seats) until it prints `FINAL genus 1 (PASS)`. Then `clipcheck.py`, `thick.py` with `thin_class.py`, and `check_settings.py`. Render with `render_mesh.py` (`SHARP=180`).
3. **Mesh and count bodies.** `python make.py <piece> stl` meshes the SDF, bridges floating metal to the main body, drops cut debris under 1 mm³, and prints `bodies N`. A single piece must print `bodies 1`. An earring pair prints `bodies 2`, one per earring. Anything else is a defect: fix it in the generator, never by hand.
4. **Check the casting.** `python -I check.py <folder>` reports watertightness, size, volume, sterling grams and dwt, and ray-sampled thickness (5th percentile and minimum). Hold the floors in `references/casting-rules.md` (0.8 to 1.0 mm minimum on veins, wires and prongs). Before sending files to a vendor, hold that vendor's floor too (Materialise OnSite brass: 0.8 mm everywhere, tips included): `python -I scripts/wall_check.py PART.stl 0.8` must print `thin 0` (see "Vendor minimums" in casting-rules.md).
5. **Check the stones.** Run `python scripts/check_stones.py` on the piece's stone list (`--jewelry` for mm, `--furniture-cm` for furniture kits). Every stone must come back OK, which means it is a stock calibrated size you can buy. Swap any LARGE or NO stone before rendering, using `references/stone-sourcing.md`.
5b. **Check the settings can be made.** `python scripts/check_settings.py OUT/<piece>.stl OUT/<piece>.json` (add `--units cm` for furniture). Every stone must be held (3+ claws or beads with no gap of 180 deg, 4+ for fancy shapes, or a bezel), seated, clear of metal, and 0.3 mm from its neighbours. Leather, straps and closures on furniture pieces: `python scripts/check_soft_parts.py` (see `references/buildable.md`). **Every non-rigid part** (leather, laces, straps, cushions, foam, the board inside a cushion) also gets a build spec (material, thickness, how it is cut, how it attaches and with what fasteners, how it is tensioned, how it opens, what load it takes, how it is replaced) and must pass `python scripts/check_soft_build.py --frame FRAME.stl --spec SPEC.json`, with an exploded build diagram on the sheet. A soft part with no spec fails. Fix FAILs in the generator before rendering. Multi-part pieces (tools, cages, stands) also run the assembly check in `references/buildable.md`, and its clipping check (check 5, `scripts/check_assembly.py`) runs on every piece before every render, changed or not: nothing may pass visibly into anything else.
5c. **Check every stone head is tied in.** `python scripts/check_joints.py OUT/<piece>.stl OUT/<piece>.json` finds, for each stone, the narrowest place in the 3 mm round its setting where metal links it to the rest of the piece, and fails a head held by one link or by less section than about 0.12 x D squared mm2. Hanging drops (tagged `drop` by the hang helper) only need their stalk. Then look at that spot in the main view: a head must also *read* tied in (members flow into it, wrap under the cup or root into a seat), never a vine tip touching the gallery's side. The numbers pass some heads that still look perched. It needs a solid mesh: an unrepaired mesher STL voxelizes as a skin only and reads every link far too thin, so the script runs `repair_stl.py` first when the filled volume comes up short (keep the two scripts together). Run it on all pieces, not only the flagged one: on Bombyx it also caught claw-set eyes floating in open plume loops (Senmurv) and a big stone on the end of a single trunk (Tillya).
5d. **Check how members end and meet.** `python scripts/kit/check_members.py <piece> ...` reads the SDF scene (no mesh) and fails: NUB, a stroke that stops at full width with its round cap showing (in air or half out of the member it butts into); CROSS, a stroke running over a carved leaf or feather away from the blade's root; BOLT, a separate needle cone started inside a much wider body, so the member necks to a pinched spike; HOLE, on rings, any metal below the band's inner face. The clipping and joint checks pass all four, because metal fused into metal is neither clipping nor a weak joint (Bombyx review 2: a vine stalk laid across its leaf, a blunt pin end, bolted streamer points, spikes in a finger hole). Fix every fault in the generator; never raise the thresholds to pass a piece. Bought findings (`ear_wire`, `stud_post`, `pin:`) and claws are exempt.
5e. **Check it stands, and settle what hangs.** Anything shown standing or lying (sawhorses, furniture castings, a ring or pendant laid flat): `python scripts/check_rest.py OUT/<piece>.stl --feet N` (add `--units cm` for furniture) fails a piece that rocks on a short foot, rolls, or tips over. Chains, cords and pendants on a form are posed by a Blender rigid-body or cloth settle, never by hand, then clipping-checked (`references/physics.md`).
6. **Render, on a cloud machine.** Never on the client's own computer: `render_square.sh` refuses to run on a Mac. Big jobs (animations) go to a render farm. `bash scripts/render_square.sh <piece>` renders four views (hero plus three angles) in a white light tent with real silver and faceted stones, and composes an Instagram square. It keeps the full build log in `<OUTSQ>/_logs/<piece>.txt`. Anything shown to the client renders with the photographic look: `LOOK=fidelity PRESO=1400 PSPPO=96` (oxidised sterling, a hard low sun, a white sweep that keeps the cast shadow, macro depth of field). Read `references/render-fidelity.md` first: the soft tent alone reads as grey CG chrome next to a photo of real cast silver. Pieces shown in a built world (a reel's grass field, a room, a landscape) follow `references/environments.md` instead: one aimed key with a pool, light-linked off the water, height-falloff mist, low 28 to 35 mm camera, and the `scripts/env/env_grade.py` finish, checked with `scripts/env_check.py` beside the reference.
7. **Check against the references (the loop).** Put the square next to the named references and list what reads robotic. `references/check-loop.md` has the checklist and the flags that keep coming back. Fix, re-render, repeat. Show the client only squares that passed.
8. **Fan out, frozen.** For more than a few pieces, freeze the shared code (`python scripts/codeversion.py freeze r4 <files> > CODE_VERSION.txt`), give each piece its own machine, and follow `references/render-farm.md`. Render jobs never edit shared files. They report flags, and one owner fixes the kit centrally, bumps the version (fix1, fix2, fix3) and names the pieces to re-render. `scripts/piece_job.sh` runs one piece end to end (mesh, casting, stone and setting checks, square, web GLB) with a report per piece; collection-scale lessons are at the end of `references/check-loop.md`.
8b. **Sameness check.** Before any sheet or page, run `scripts/check_sameness.py` on the new squares against every earlier collection and any sibling collection (`references/check-loop.md`, end). Fix every SAME, ECHO, RESKIN or TYPES flag in the design, not with a new seed or stone.
9. **Sheet.** Assemble the passed squares into one comparison sheet, the client's picks first. Copy every square the client picks into a `picks/` folder that no re-render writes to, so a later round can't lose it (nine picks lost their images on 18 Nov).
10. **Public text.** Notes, sheets and site copy describe each piece on its own terms: no reference artists' names, file names or "inspired by" lines. The brief keeps the influences; the public never sees them.

## Machined jewelry
When the brief asks for machining (turned, milled, knurled, geared, screwed together) use `scripts/machined/` and read `references/machined-jewelry.md` first: exact CSG instead of SDF, assemblies of separately made parts with a per-part and clipping check, two-tone by finish, balls instead of cut stones. Several carving rules below flip for it.

## Furniture-scale castings
Read `references/furniture-scale.md`. The worked example (`scripts/sawhorse/`) keeps the proportions of a classic wooden sawhorse, recasts the frame in metal with the same kit, and adds a removable leather seat that drops over the rail on a slot. The rules: the bare frame must still work (flat rail top at the original height, nothing above that line), the metal is one watertight casting, and every sheet shows the seat on and off. For anything people sit or stand on, also run a load and tipping check. Before showing any pass, run the design-coherence check (`references/design-coherence.md`): every part listed with its language, one close-up per part, no plain or bead-tipped part on a carved piece.

## Getting it made
When designs are final, read `references/production-and-delivery.md`: who casts, prints, sets stones and finishes each part, what the client does by hand (leather), bought hardware, and the stone-cup rule for steel furniture.

## Rules that are easy to break
- No bead rows anywhere in a carved piece: no strung beads, ladder ticks, dot rows, milgrain, rope or knurled rims. They read machined. (A machined collection is the exception: there knurling, even rows and straight rods are the point, but each must be a real cut detail of the real part. See `references/machined-jewelry.md`.)
- Every stroke swells and ends in a needle. No even-gauge tubes, no ball ends, no straight rods.
- Stones are stock calibrated sizes you can actually buy (run check_stones.py). Furniture kits are in cm, so cap their stones. Rounds of 2 mm and under are bead-set, centre ovals and drops get claws, wing panes sit in 0.7 mm open-backed bezels.
- Join members in the geometry so they fuse; `make.bridge` struts are a safety net, not a design tool.
- Don't edit shared code while renders that import it are running.
- One piece per machine when rendering in bulk, always on cloud machines.
- Straps and ties are constant-thickness leather that a person could cut, sew and buckle; anything round the frame opens or is sewn on (`check_soft_parts.py`).
- Claws reach over the girdle and seats stay clear (`check_settings.py`); a stone a setter can't set doesn't go on a sheet.
- No ball joints, umbrella ribs or wire outlines that no caster could make in one pour.
- No open-wire panels at sizes where the cells read as holes (about 8 mm across and up): leaves, petals and wings big enough to see are solid and carved, a polished rib with engraved veins (the feather primitive used as a broad blade, `skew=1, notches=0`; see `carved()` in the Bombyx kit). The best-detailed piece in a collection sets the surface bar for all of them.
- Every end of every stroke either draws out to a point or is buried whole in the member it joins: no round capsule ends showing (`check_members.py` NUB). A point is the member's own taper, never a cone bolted onto a fat end (BOLT).
- A stem, stalk or tendril meets a leaf or feather only at its root, leaving through an open sector beside it; nothing lies across a carved face (CROSS).
- Nothing in a ring's finger opening: claws, drops and spikes stay above the band's inner face (HOLE). Hanging drops on a ring hang along the band's tangent and ride clear of it.
- Findings are bought, not modelled: cast a loop (earring drops) or a flat pad (studs, hair clips) and name the bought ear wire, post or barrette in the spec. A fused fake clip spring or ear wire is not a design.
- Carve to hold patina: engraved lines and barbs 0.15 to 0.3 mm deep with a V or U section, at least three relief depths on the focal area, and no mesh smoothing above `SMOOTH=3`. A scratch under 0.1 mm deep vanishes in the render and on the real piece (`references/render-fidelity.md`).
- Free tips meant to be points end in a cast point (about 0.15 mm radius at the very end, grown from the member's full section), never a rounded nub.
- A contour the eye reads as one curve (a crescent's inner edge) is built as one curve, with no knuckle where members meet it.
- Bundles of ribbons, vines or strands follow one rule (an even fan, a shared wave, graded lengths, stacked in depth), never random phases that cross and merge.

## Excuses that don't count
Each of these is a shortcut that ends in a broken result. If you catch yourself thinking the left column, do the right column.

| The excuse | What to do instead |
|---|---|
| "Wall thickness looks OK" | Run the casting check; thin walls and trapped volumes fail. |
| "The stone/chain only touches a little" | Run the clipping check; metal through stone, glass or cord is a fail. |
| "This set looks varied enough" | Run the sameness check against earlier collections and siblings. |
| "The render is clean, the light tent is fine" | Hold the hero next to a photo of real cast, oxidised sterling and run the check in `references/render-fidelity.md`. Uniform mirror silver, no cast shadow and 24 samples read as CG. |
| "The environment is lit, you can see everything" | Even light is the flat v10 look. One aimed key with a pool that falls off, the lamp light-linked off the water, and the grade on every frame (`references/environments.md`). |
| "The union says one body, so it's solid" | Check the genus too (`finish.py` prints it). One watertight body at genus 84 had that many pinhole tunnels (`references/insert-layer.md`). |
| "Checking every stroke against its neighbours is safest" | It threw out a sixth of the ornament and the lead sweeps. Place for the design, then let `finish.py` close the tunnels. |
| "check.py says 0.16 mm walls, the relief must be too thin" (or "check.py passed") | On layered relief its normal rays measure across ridges. Use `thick.py` for walls and the genus for hidden holes. |
| "A flat underside is fine, it's sunk under the surface" | On a curved shank the chord lifts off the surface and traps air. Keep `conform=True`. |
| "While I'm in here I'll also tidy/refactor this other bit" | Change only what the task needs. Smallest diff that works; no new options, helpers or files nobody asked for. Note other ideas for later instead. |
