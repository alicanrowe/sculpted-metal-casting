# Influence weighting

A brief names several influences (artists, brands, periods). One piece blends them; a variant set pushes each one hard so the client can see the range.

## For one piece
Write the weights down before modelling, for example "liquid-chrome artist 50, Art Nouveau 30, carved-feather jeweller 20". The check pass compares the render against each lead in that order.

Get each influence right on its own first. The bar the client set: be able to make a piece that convincingly passes as either artist alone before mixing them.

## For a variant set
Give each variant one lead and say in a line what it means in form, finish and hardware. The worked sawhorse set:

| Code | Lead | Reads as |
|---|---|---|
| CARVED | carved-feather jeweller | carved all over, stone clusters, melted drips |
| LIQUID | liquid-chrome artist | pure liquid chrome, swells to needles, curls, no carving |
| EDGE | structural leather/objects brand | knife-edge blackened plate, honed bright edges; the leather and hardware (couplers, Torx heads, turnbuckles) are the ornament |
| WASH | bird-named bag brand | bone forms (crane legs, toe claws), washed oxidised finish, a wrapped-cloth seat on tethers |
| STAGE | gallery-store | one oversized motif fills the frame |
| THREAD | experimental menswear | fine wire, pale stones, quiet |
| THORN | tattoo flash | barbs and thorns up every member |
| SWARM | both artists, multiplied | many small moths along crossing flight paths that also brace the frame |

## Brand cues, used lightly
Brands that aren't metalwork give direction, not forms: naming (a single poetic noun plus an archive code; pieces named after birds), the clasp or post designed as a visible part, an oxidised finish option beside bright silver, a launch framed as a show.
